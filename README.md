# European Sentinel-2 Satellite Land-use Classifying
This is a Convolutional Neural Network (CNN) classifying Sentinel-2 satellite imagery into 10 land-use classes:
* Forest
* Residential
* River
* Highway
* Agricultural
* Industrial
Using the publicly avaliable **EuroSAT** dataset.

## Technologies
* Python
* PyTorch
* NumPy
* Matplotlib
* Jupyter Notebook
